# AcessoVivo — Portal de Inclusão

Site responsivo inspirado nas imagens fornecidas.

## Como executar
1. Extraia a pasta/arquivo ZIP.
2. Abra `index.html` no navegador ou abra a pasta no Visual Studio Code.
3. Opcional: use a extensão Live Server para visualizar enquanto edita.

## Arquivos
- `index.html`: estrutura e conteúdo.
- `css/style.css`: aparência, responsividade e modos visuais.
- `js/script.js`: filtros, pesquisa e ferramentas de acessibilidade.

## Funções implementadas
- Filtro por tipo de deficiência e busca por texto.
- Aumento e restauração do tamanho do texto.
- Alto contraste, modo escuro e destaque de foco.
- Modo de leitura com espaçamento ampliado.
- Leitura em voz alta usando os recursos do navegador.
- Menu responsivo, navegação por seções e links externos/telefones clicáveis.

Observação: os telefones e serviços exibidos são exemplos de interface; confirme informações e disponibilidade nos canais oficiais antes de usar.
